수식v3 설정 · 환경 사건

수식v3는 풀 격자와 동물의 이동·섭식·사냥·에너지·번식·죽음을 계산하는 개체 기반 모델입니다. 로트카–볼테라 미분방정식을 직접 푸는 방식은 아닙니다.

풀 재생 속도: 한 틱에 각 칸에 더해지는 풀의 양입니다.
토끼·여우 번식 확률: 번식에 필요한 에너지가 있는 개체가 틱마다 새끼를 낳을 확률입니다.
사냥 성공 확률: 배고픈 여우가 포획 거리 안의 토끼를 잡을 확률입니다.

유효한 값을 입력하면 이후 계산부터 적용됩니다. 0.05는 5%입니다. 가뭄·여우 사냥 버튼은 아래 개체수 조절 영역에 있습니다.

가상 시간 1 = 10틱입니다. 2틱마다 모은 최근 150개 표본으로 토끼·여우의 변동계수를 구합니다. 둘 중 큰 CV가 0.12 미만이면 안정 평형, 0.4 미만이면 동적 평형, 그 이상이면 불안정입니다. 이는 최근 변동에 대한 판정이며 장기 공존을 보장하지 않습니다.

초기 풀은 입력한 총량을 60×40칸에 균등하게 배치합니다. 풀 총량 1,680은 평균 70%입니다. 풀이 0이어도 재생될 수 있지만, 멸종한 토끼·여우는 직접 추가해야 다시 나타납니다.

개체군과 수량을 선택한 뒤 ＋ 추가 또는 － 줄이기를 누르세요. 한 번에 1~3,000 사이의 정수로 조절할 수 있습니다. 현재 수량보다 많이 줄이면 0까지만 감소합니다.

시간과 실행·일시정지 상태는 유지되며 변경은 즉시 적용됩니다. 실제 변경량은 그래프와 변경 기록 표에 남습니다.

v3의 생산자는 풀 총량 Σg입니다. 최대 2,400이며 1,680은 평균 70%입니다. 풀 추가는 최대 2,400까지만 적용됩니다. 추가한 동물은 무작위 위치에서 시작하며, 토끼의 초기 에너지는 1, 여우는 1.2입니다.

가뭄: 모든 칸의 현재 풀을 15%만 남깁니다. 이후 풀은 설정된 속도로 재생됩니다.
여우 사냥: 여우마다 70% 확률로 제거합니다. 실제 제거 비율이 정확히 70%인 것은 아닙니다.

환경 사건은 v3에서만 사용할 수 있으며 일시정지 중에도 즉시 적용됩니다.

시뮬레이션 안내

  1. v1·v2는 연속 개체수 모델, v3는 공간·에너지 기반 개체 모델입니다.
  2. 기본값은 v3이며, 풀 70% · 토끼 60 · 여우 18로 시작합니다.
  3. v3의 풀은 60×40칸에 분포하며 총량 2,400이 평균 100%입니다.
  4. 초기 풀은 균등 배치하고, 초기 동물은 무작위 위치에 생성합니다.
  5. 조건 적용·초기화는 시간·그래프·변경 기록을 초기화합니다. 선택한 모델과 v3 설정값은 유지됩니다.
  6. 직접 조절·환경 사건은 시간과 실행 여부를 유지하며 즉시 적용됩니다.
  7. v3의 풀은 0에서 재생될 수 있지만 멸종한 동물은 직접 추가해야 합니다.
  8. v1·v2의 이동은 시각 효과이고, v3의 위치는 섭식·사냥에 사용됩니다.
  9. v3의 공간은 가장자리가 반대편과 연결되며 거리 계산도 이를 반영합니다.
  10. v1·v2의 화살표는 순간 변화율, v3는 직전 틱의 자연 변화입니다.
  11. 피라미드 과거 비교에는 직접 조절·환경 사건도 포함됩니다.
  12. 모델 전환은 시간과 기존 기록을 유지합니다. v3 진입 시 위치·에너지 상태를 새로 구성하고 동물 수는 정수로 맞춥니다.
  13. 서로 다른 모델의 시간 단위는 생태학적으로 보정된 동일 단위가 아닙니다. 모델 전환 지점은 그래프에 별도 마커로 표시하지 않습니다.
  14. 모든 데이터는 메모리에만 있으며 새로고침하면 사라집니다.

시간과 기존 기록은 유지됩니다. v3로 전환할 때 풀 총량은 2,400 이하여야 하며, 동물 수에 소수가 있으면 확인 후 반올림합니다.

수식v1

생산자의 로지스틱 성장, 토끼의 섭식, 여우의 포식, 소비자의 사망과 밀도 영향을 계산합니다. 환경은 확률적으로 변하며 성장률·수용력·사망률에 영향을 줍니다. 기준 환경에서 500 / 100 / 20이 양의 기준 평형입니다.

수식v2

같은 상태에서 v1의 증가·감소 방향과 변화율 0 조건을 유지하면서 자연 변화율을 완화합니다. 단순 배속 변경이나 과거 상태를 참조하는 시간 지연 모델이 아닙니다.

F2 = F1 / (2 + |F1| / (0.12 × max(N, 1)))

N이 1 이상이면 순간 상대 변화율의 크기를 가상 시간당 12% 미만으로 제한합니다. 한 시간 동안 누적 변화가 반드시 12% 이하라는 뜻은 아닙니다. 직접 조절은 즉시 적용되고 환경 갱신 속도도 그대로입니다.

수식v3 · 개체 기반 모델

매 틱 풀 재생 → 토끼 행동 → 여우 행동 순으로 계산합니다. 새끼는 부모 위치에서 태어나 다음 틱부터 행동합니다. 행동 순서는 무작위로 섞어 순서 편향을 줄입니다.

g ← min(1, g + 풀 재생 속도)

토끼: 속도 0.55, 방향 변화 ±0.45, 풀 섭식 최대 0.3, 에너지 전환율 0.7, 에너지 소모 0.03, 최대 에너지 3. 에너지가 1.6보다 크면 설정 확률로 번식하며 부모와 새끼가 에너지를 절반씩 나눕니다.

여우: 에너지 1.9 미만일 때 반경 6 안의 가장 가까운 토끼를 추적합니다. 속도 0.65, 포획 거리 1.85 미만, 포획 에너지 +0.5, 틱당 에너지 소모 0.018입니다. 에너지가 1.8보다 크면 설정 확률로 번식합니다. 토끼·여우 모두 에너지가 0 이하이면 죽습니다.

유한한 풀, 배부른 여우의 사냥 중단, 공간적 만남이 개체군 상호작용에 영향을 줍니다. 확률과 초기 상태에 따라 진동·멸종·불안정이 나타날 수 있으며 항상 평형이나 공존에 도달하는 것은 아닙니다.
