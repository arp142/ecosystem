풀 → 토끼 → 여우의 상호작용을 관찰하세요. 기본 모델은 수식v3입니다. 토끼·여우의 에너지를 변경하면서 생존과 번식의 차이를 비교할 수 있습니다. 공존이나 평형이 항상 보장되지는 않습니다.

수식v3 설정 · 토끼·여우 에너지

수식v3는 풀 격자와 동물의 이동·섭식·사냥·에너지·번식·죽음을 계산하는 개체 기반 모델입니다. 가상 시간 1은 10틱입니다.

에너지 소모 / 틱: 틱마다 잃는 에너지입니다. 높이면 더 빨리 굶습니다.

시작 에너지: 초기화하거나 직접 추가하는 개체에게 적용됩니다. 기존 개체의 현재 에너지는 바꾸지 않습니다. 번식한 새끼는 부모 에너지의 절반을 받습니다.

번식 필요 에너지: 현재 에너지가 이 값보다 클 때 번식을 시도합니다. 실제 번식 성공 여부는 번식 확률에 따라 결정됩니다.

토끼: 한 틱에 풀을 최대 0.3 먹으며 먹은 양의 70%를 에너지로 얻습니다. 이동 → 섭식 → 에너지 소모 → 사망·번식 순서입니다.

여우: 에너지가 1.9 미만이면 사냥합니다. 토끼 한 마리 포획 시 에너지 0.5를 얻습니다. 이동·사냥 → 에너지 소모 → 사망·번식 순서입니다.

최대 에너지는 모두 3이며 0 이하가 되면 굶어 죽습니다. 번식 필요 에너지를 3으로 설정하면 번식하지 않습니다.

유효한 값은 자동 적용됩니다. 잘못된 값은 적용되지 않으며 마지막 유효 설정을 유지합니다. 설정 변경 이력은 별도로 저장하지 않습니다.

여우 추천: 소모 0.015 · 시작 1.2 · 번식 기준 2.2

개체수 조절 / Add & Remove

한 번에 1~3,000 사이 정수로 조절합니다. 현재 수량보다 많이 줄이면 0까지만 감소합니다. 시간과 실행 여부는 유지됩니다.

v3의 풀 총량 상한은 2,400입니다. 직접 추가한 토끼·여우는 무작위 위치에서 시작하며 각 종의 현재 설정된 시작 에너지를 받습니다.

가뭄은 풀을 15%만 남깁니다. 여우 사냥은 여우마다 70% 확률로 제거합니다. 환경 사건은 v3에서만 사용할 수 있습니다.

시뮬레이션 안내

  • v1·v2는 연속 개체수 모델, v3는 개체 기반 모델입니다.
  • v3의 풀은 60×40칸이며 총량 2,400이 평균 100%입니다.
  • v3에서는 위치가 섭식·사냥에 영향을 줍니다.
  • 공간 가장자리는 반대편과 연결됩니다.
  • v1·v2의 이동은 설명용 시각 효과입니다.
  • v3의 풀은 0에서도 재생될 수 있습니다.
  • 멸종한 동물은 직접 추가하기 전에는 다시 생기지 않습니다.
  • 번식 시 부모와 새끼가 에너지를 절반씩 나눕니다.
  • 새끼는 다음 틱부터 행동합니다.
  • 직접 조절은 시간과 실행 여부를 유지합니다.
  • 초기화하면 시간·개체수·그래프·변경 기록을 초기화합니다.
  • 선택 모델·배속·에너지 설정은 초기화해도 유지됩니다.
  • 데이터는 메모리에만 있으며 새로고침하면 사라집니다.
  • 개체가 매우 많아지면 성능이 저하될 수 있습니다.
사용할 모델 선택

v1: 로지스틱 성장과 섭식·포식·사망·밀도 의존 감소를 사용합니다. 기준 환경에서 500 / 100 / 20이 양의 기준 평형입니다.

v2: F2 = F1 / (2 + |F1| / (0.12 × max(N, 1)))
같은 상태에서 변화 방향과 변화율 0 조건을 유지하며 자연 변화를 완화합니다. 단순 배속 변경이나 시간 지연 모델이 아닙니다.

v3: 풀 재생 → 토끼 행동 → 여우 행동 순서로 계산합니다. 에너지 설정은 v3에서만 사용합니다. 로트카–볼테라 미분방정식을 직접 푸는 모델은 아닙니다.

모델 전환은 시간과 기존 기록을 유지합니다. v3 진입 시 동물 수를 정수로 맞추고 위치·에너지를 새로 구성합니다. 모델 간 시간 단위는 생태학적으로 보정된 동일 단위가 아닙니다.
